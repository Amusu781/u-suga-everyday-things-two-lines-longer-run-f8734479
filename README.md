## The entry

Two lines, and nothing else — a queue explained to a 10-year-old through
one analogy, then one honest sentence about what that analogy maps and
what it leaves out:

> A queue is a row of dominoes that refuses to fall, each person shuffling forward one small step at a time.
> It maps the single-file line and the slow forward shuffle, but leaves out that one nudge topples a domino, while people step forward only when they decide to, never because something pushed them.

## How it works

`main.py` (Python 3.13, standard library only) writes the two lines above
to `/output/entry.txt` — no network, no randomness, no model calls,
so both grading runs write byte-identical output.

## Run it

```sh
python3 main.py
```
